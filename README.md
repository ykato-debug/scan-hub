# 3Dスキャン統合ツール

建物の3Dスキャン（GLB・STL・OBJ・PLY・DAE）を、1つの画面で合成・確認・計測・図面化するWebアプリです。

## 使い方
`index.html` をブラウザ（Chrome / Edge / Safari）で開きます。インストールは不要で、ネット接続がなくても動きます。

## モード
1. **合成**：室内と屋外のスキャンを位置合わせして1つにする
2. **確認**：断面パース表示、軸合わせ、PNG出力
3. **測る**：BM（基準点）からのレベルと距離を測る
4. **図面化**：平面CAD（DXF・PNG・PDF）、展開図（PNG・PDF・ZIP）

読み込んだモデルと軸合わせは、全モードで共有されます。データはすべて端末の中で処理され、外部には送信されません。
